# Agent Customization — Workspace Skill

This skill implements a concise, repeatable workflow for creating or fixing
agent customization artifacts in a repository (prompts, instructions,
agents, SKILL.md, copilot-instructions.md, AGENTS.md).

## When to use

- Add or update per-repo prompts and instruction files that should be
  discoverable by the agent.
- Fix silent YAML/frontmatter errors and `applyTo` misconfigurations.
- Package multi-step workflows (templates + prompts + helpers) as a reusable
  skill in the repository.

## Decision flow (quick)

- If configuration applies globally to the project → create `copilot-instructions.md` or add to `AGENTS.md`.
- If the customization targets specific files → create a file with `applyTo` globs.
- If the task is procedural and multi-step with assets → create a `SKILL.md` bundle.

## Skill actions (what this skill does)

1. Ask clarifying questions (scope, user vs workspace, trigger keywords).
2. Generate a file scaffold with required YAML frontmatter and recommended fields.
3. Run a validation pass:
   - YAML frontmatter presence and syntax
   - `name` matches folder name when required
   - `description` includes trigger phrases
   - `applyTo` uses specific globs (warn if `"**"` used)
4. Offer suggested example prompts and a minimal test checklist.

- Quote `description` values in YAML if they contain `:` or special characters.
